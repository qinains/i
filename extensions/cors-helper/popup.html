预检修复（高级 · Chrome / Edge）

仅对当前标签页和指定 API 的 OPTIONS 合成 204，不修改真实 POST 的状态或内容。需要高权限调试器，浏览器会显示调试提示。调试器可能接收匹配请求的认证头等元数据；本实现不记录或保存密钥、正文或回复。不用于不可信页面。

默认关闭，需要单独确认。

手动修改地址

仅在自动识别失败时填写。包含 /chat/completions 或 /v1/messages 等实际请求路径，不要填写密钥。

范围与限制

普通模式只修改本标签页到此 API URL 的 CORS 响应头，不修改 HTTP 状态。高级预检修复需单独开启，仅合成 OPTIONS 成功响应；真实 API 鉴权、TLS 和额度错误不会改变。浏览器重启后需重新启用。

仅用于可信的 Harness 页面。保持网页连接方式为「直连」。不支持 file://。Firefox / Safari 包不含调试器预检修复功能。
