More connection options

        
Desktop CORS extension
          
Download our opt-in CORS helper. Ordinary mode changes response headers for one tab and the exact API URL; it cannot fix rejected OPTIONS, authentication or TLS failures.

          
Chrome / Edge ZIPFirefox ZIPSafari source ZIP

          
Chrome / Edge: OPTIONS 401/403/405 can use the separately confirmed Preflight repair mode. Requires debugger permission; real API authentication is unchanged.

          
    
            
  1. Chrome / Edge: unzip, open chrome://extensions or edge://extensions, enable Developer mode, then Load unpacked.
    2. 
            
  2. Firefox: about:debugging, This Firefox, Load Temporary Add-on. Unsigned packages last until restart.
    3. 
            
  3. Safari: ZIP is source, not an installer. Convert and build with Xcode, then enable the containing app extension. See README in the ZIP. iPhone requires a signed containing app.
    4. 
            
  4. Save API settings, open the extension, click Start, and confirm. The button becomes Stop. Keep Direct selected and retry manually. It reads only the public API URL from the page.

Saved locally

      
Workspace files, conversations, tabs, drafts and reading position are saved on this device. Interrupted requests and approvals are never replayed after reload.

      
OPFS stores files; IndexedDB stores conversations.

      
No task round limit. Runs until the model finishes, you stop it, or an error occurs. Keep this page foregrounded; provider and browser limits still apply.

      

      
Site-data clearing or storage eviction can delete data. ZIP backs up files, not conversations. A sudden termination may lose the last unsaved display fragment.

      
      
Install / offline use
On iPhone, open in Safari, Share → Add to Home Screen. Open once online to cache. AI still needs the network; files and ZIP work offline. Keep this app foregrounded during generation.

    

    

      

      
Theme changes apply immediately and are saved separately from API credentials. Previewed websites keep their own styles.

      

      
Task and model text retain their original language.
