04 / SECURITY, NOT A BLACK BOX

连接由你选，边界说清楚。

本地存储不等于本地推理。你应该知道哪些数据留在设备、哪些会发送出去。

/01

请求发给谁

直连时，密钥与模型请求发往你选择的 API，不经本站后端；使用自建 Relay 时会经过你的中继。任务消息、选用的文件内容与图片会发送给该模型服务。

/02

记住密钥，由你决定

可选保存在当前浏览器的 localStorage，或仅在内存中使用。保存不是加密保险箱：同源脚本或有权限的浏览器扩展可能读取。共享设备请勿记住密钥。

/03

WASM 插件的权限边界

WASM 插件没有直接访问 DOM、localStorage 或连接配置的接口。文件访问与私有存储由宿主按授权提供；插件可看到你传入的内容。原生 worker 是可信进程，不是沙箱。

/04

文件属于你的设备

持久工作区保存在本地 OPFS，临时 /tmp 与之分离。清除网站数据会删除工作区，请及时导出 ZIP。

/05

预览脚本，需要信任

HTML 预览使用隔离 iframe，不开放宿主同源权限。仅对可信内容开启 JavaScript；脚本可以读取预览快照中的文件。浏览器版禁用本机 shell，不代表生成内容天然安全。

/06

不隐藏浏览器限制

直连需要 API 支持 CORS，也可用自建中继或桌面扩展。PWA 不绕过 CORS；扩展不修复认证或 TLS 错误。

仅安装可信的浏览器扩展。预检修复使用高权限 debugger，可能接触匹配请求的认证元数据；它与隔离的 WASM 插件不同。完整安全说明与漏洞报告 →
