DOWNLOAD / INSTALL / START

选一个客户端，开始你的任务。

原生客户端适合本机开发；浏览器工作台无需安装。连接你自己的模型 API 即可开始。

WEBASSEMBLY / PWA

不用下载，直接打开。

支持电脑与手机浏览器。在自己的设备上管理文件与会话，模型请求需要联网。

打开浏览器工作台

浏览器版不执行本机 shell。API 需支持 CORS，或使用你自己的中继。

  1. 打开并连接

    填写 API URL、模型与 API key。配置可选择保存在当前浏览器。

  2. 开始第一个任务

    上传文件或直接描述任务；支持预览 HTML、修改文件和导出 ZIP。

  3. 可选：安装为 PWA

    桌面浏览器选择“安装应用”；iPhone Safari：分享 → 添加到主屏幕。安装不会绕过 CORS。

从源码安装

需要 Git 与 Rust 工具链，在仓库目录执行：

git clone https://github.com/qinains/i.git
cd i
cargo install --path . --locked --features bundled --bin i
i setup
i start -C .
