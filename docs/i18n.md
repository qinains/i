## 如何选择语言

Web 工作台首次访问读取 `navigator.languages`，优先使用浏览器支持语言中的第一项。
例如 `es-ES` 对应 `es`、`pt-BR` 对应 `pt`、`ar-SA` 对应 `ar`。
中文根据 `Hans` / `Hant` 及地区映射到简体或繁体；显式文字体系优先于地区。
不支持的首选语言会继续匹配后续偏好，最终回退到英语。

在设置 → 外观中可切换全部 17 种语言。选择立即生效，独立保存为 `i_lang`；
不会因此保存 API 密钥、发送模型请求，或把模型连接切换为其他账号。
切换连接保留当前界面语言。浏览器禁止本地存储时，本页仍可切换，但不能跨刷新记住。

官网使用同一清单与地区匹配规则，语言选择独立保存为 `lninl_site_language`。
官网与工作台可以分别选择语言；它们不会修改用户任务、模型回复、文件内容或自定义标题。
技术文档正文仍保留原来的中文或英文，不会自动发送给模型翻译。

原生客户端优先使用 `I_LANG`，否则读取 `LC_ALL`、`LC_MESSAGES`、`LANG`，
最后回退到英语。例如：

```sh
I_LANG=es i
I_LANG=ar i
LANG=pt_BR.UTF-8 i
```

原生安装与配置词条已嵌入程序，进入没有 `locales/` 的项目目录仍可使用。
当前目录下有效的 `locales/<语言>.json` 可以覆盖对应内置词条；缺失词条使用内置译文。
这不意味着所有终端诊断、上游错误和模型回复都会翻译。

## 翻译文件

```text
locales/languages.json        # 唯一语言清单、原生名称与界面方向
locales/<代码>.json          # 原生安装、配置与基础状态词条
locales/web/<代码>.json      # 工作台界面、设置、确认和状态提示
locales/site/<代码>.json     # 官网、下载、导航与安全说明
```

各目录以 `en.json` 定义完整键集。原生、网页和官网是不同使用场景，不能用原生词条替代网页翻译。
网页键使用稳定的英文源标识，官网使用 `hero.first` 等语义标识。翻译应表达原意，不机械逐字转换。
关联短句按目标语言习惯连接；完整英语短句可以保留句号，中文独立标题通常不需要末尾句号。

### 占位符与技术内容

必须保留 `{name}`、`{path}`、`{count}` 等命名占位符，原生词条还使用 `{}`、`{0}` 等格式。
不要翻译 API URL、命令、参数名、文件路径或品牌标识。

阿拉伯语页面设置 `dir="rtl"`。界面布局随之调整，但代码、API URL、文件树路径仍使用 LTR；
用户输入、排队消息和模型输出按自身文本决定方向。动态提示中的占位值使用方向隔离，
不需要在翻译 JSON 中插入不可见的 bidi 控制字符。

安全说明必须保留事实边界：本地保存不等于本地推理，模型所需内容会发送至所选 API；
记住密钥不是加密保险箱，临时文件不保证跨刷新保留，浏览器扩展与 WASM 插件权限不同。

## 更新或贡献翻译

修改上述 JSON 后执行：

```sh
cargo run --locked --manifest-path tools/site-tool/Cargo.toml -- translations
cargo run --locked --manifest-path tools/site-tool/Cargo.toml -- translations --check
npm --prefix web test
node scripts/build_pwa.mjs
cargo test --locked --manifest-path tools/site-tool/Cargo.toml
```

生成器更新 `web/` 与 `site/assets/` 中的语言模块，以及 `src/locales_generated.rs`。
这些生成文件提交到仓库，但不要手动编辑。发布构建与 CI 使用 `--check` 拒绝过期生成物。
键缺失、重复、空译文、格式占位符错误、API URL 被改写或手动插入 bidi 控制字符都会失败。
语言清单不是“显示一个选项”的开关；每种新增语言必须提供三套完整词条并通过测试。

浏览器回归测试：

```sh
npm --prefix web run test:browser -- tests/i18n.spec.mjs
```

新增语言时，在 `locales/languages.json` 注册代码、原生名称和方向，添加三套词条，重新生成，
并测试系统语言、手动选择、刷新恢复、手机布局及无意外模型请求。译文与项目同为 MIT 许可。
